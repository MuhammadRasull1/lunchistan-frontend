# Lunchistan — СТАТУС.md

Обновлено: 25.09.2026. Три приложения + бэкенд:

| Что | Репозиторий | Прод | Деплой |
|---|---|---|---|
| Клиент (Telegram Mini App) | `~/lunchistan-frontend` | https://lunchistan-app.pages.dev | Cloudflare Pages, сам по пушу в `main` |
| Core (кабинет владельца) | `~/lunchistan-core` | https://lunchistan-core.pages.dev | Cloudflare Pages, сам по пушу в `main` |
| Бэкенд (API) | `~/lunchistan-backend-main` | https://lunchistan-backend-worker.mansurovsvoyo.workers.dev | Cloudflare Worker: GitHub Actions `deploy-worker.yml` после смоук-теста — **работает только когда задан секрет `CLOUDFLARE_API_TOKEN`**, до этого вручную `cd cloudflare && npx wrangler deploy` |

## Находки 25.09 — ждут решения «чинить?»
Безопасность: 5 важных находок и 9 мелочей — подробности только в локальном отчёте
`~/lunchistan-backend-main/docs/security-audit-2026-09-25.md` (в git не кладётся: репозитории публичные).

Найдено сквозным тестом:
- В обычном браузере (не Telegram) нельзя оформить заказ: своя кнопка скрыта в расчёте на Telegram MainButton (`Catalog.tsx:97` — проверяется только наличие объекта, а не реальный Telegram).

- Адрес доставки необязателен — заказ уходит без адреса.
- При недоступном сервере онбординг пишет «Проверьте данные», а не «нет связи».
- Мелочи: «2 дней · 1 сотрудников · 2 порций» (склонения), названия блюд рвутся посреди слова в корзине, гарнир «flatbread» по-английски, в шапке Core на телефоне обрезана кнопка «Настройки».
