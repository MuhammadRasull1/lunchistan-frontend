# Lunchistan — СТАТУС.md

## Текущий этап
Переделка онбординга вкладки «Команды» (клиентская часть для рабочих).

## Что сделано
- Отказались от телефона в регистрации/входе: вместо `phone+password` — `name+password`.
- Бекенд: в `register` phone стал опциональным (авто-генерация `user_<hex>`); в `login` — вход по `name+password`, опционально + `companyCode` для различения однофамильцев.
- Фронтенд: вместо `TeamsAuth` создан `Onboarding.tsx` — многошаговый вход:
  1. Welcome-экран (плавное медленное появление текста: о компании, что делает).
  2. Шаг 1 — имя с валидацией `nameValidator.ts` (кириллица/латиница, 2–50, гласная, не бессмыслица типа «йцукен», нет одиночных букв).
  3. Шаг 2 — пароль (min 4).
  4. Выбор пути: логин / создать команду / войти по коду.
- Успешный вход → анимация `<reveal-overlay>`: плавное появление названия Lunchistan + компании.
- Views обёрнуты в `view__enter` (fade-up). TeamsAuth.tsx удалён.
- Сборка (`npm run build` → 453КБ) и eslint — зелёные. Бекенд smoke-тест пройден (register без phone, login по имени).
