Обновлено: 25.09.2026. Три приложения + бэкенд:

| Что | Репозиторий | Прод | Деплой |
|---|---|---|---|
| Клиент (Telegram Mini App) | `~/lunchistan-frontend` | https://lunchistan-app.pages.dev | Cloudflare Pages, сам по пушу в `main` |

## Ожидания от пользователя
- [ ] Создать токен Cloudflare API (шаблон «Edit Cloudflare Workers») и положить в секреты бэкенда: `gh secret set CLOUDFLARE_API_TOKEN` — после этого Worker деплоится сам.
- [ ] Выкатить исправления 25.09: `git push` бэкенда + `cd cloudflare && npx wrangler deploy`, затем `git push` клиента и Core (Pages деплоятся сами).
- [ ] Меню на 02.10 и дальше — в Core «Меню на дни» → «Скопировать с …».

## Ждут дядю/брата
- «Команды»: сотрудник, не выбравший день, выпадает из плана — баг или «свобода сотрудника»?
- Модуль учёта (расходы/зарплаты/закупки) — берём ли `Отчёты/Кейтеринг` за основу.
- Номер карты для оплаты P2P (Настройки в Core), если ещё не внесён.

## Открытые вопросы
- Уникальность имени в команде — на уровне API, не БД; при втором способе создавать пользователей продублировать в `schema.sql`.
