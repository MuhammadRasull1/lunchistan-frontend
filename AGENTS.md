# 🤖 Инструкция для AI-агентов

> Последнее обновление: 29.07.2026

## ⚠️ ОБЯЗАТЕЛЬНОЕ ПРАВИЛО

**Любой AI-агент, работающий с проектом Lunchistan, ОБЯЗАН перед выполнением любой задачи прочитать файлы из папки `docs/`.**

## 📂 Файлы для чтения

| Файл                 | Описание                                         |
| -------------------- | ------------------------------------------------ |
| `docs/ARCHITECTURE.md` | Архитектура, стек, структура проекта → [[ARCHITECTURE]] |
| `docs/B2B_RULES.md`  | Бизнес-логика B2B-подписки, ценообразование → [[B2B_RULES]] |
| `docs/COMPONENTS.md` | Детали компонентов, анимации, пропсы → [[COMPONENTS]] |
| `docs/STATE_MANAGEMENT.md` | Состояние, редьюсеры, derived values → [[STATE_MANAGEMENT]] |
| `docs/CHECKOUT_FLOW.md` | Процесс оформления заказа → [[CHECKOUT_FLOW]] |

## 📋 Процедура

1. **Перед любыми изменениями кода** — прочитать все файлы из папки `docs/`
2. **После любых изменений кода** — обновить соответствующие файлы в `docs/`, чтобы Obsidian-хранилище содержало актуальный контекст проекта
3. **При добавлении новых компонентов/функций** — дополнить `docs/COMPONENTS.md` разделом о них
4. **При изменении бизнес-логики** — обновить `docs/B2B_RULES.md`
5. **При изменении менеджмента состояния** — обновить `docs/STATE_MANAGEMENT.md`
6. **При изменении процесса заказа** — обновить `docs/CHECKOUT_FLOW.md`

## 🔄 После выполнения задачи

Всегда синхронизируй документацию с помощью **Obsidian WikiLinks** (формат `[[НАЗВАНИЕ_ФАЙЛА]]`):

- Обновил состояние → отрази в [[STATE_MANAGEMENT]]
- Добавил новый экран/компонент → отрази в [[COMPONENTS]]
- Изменил цены/формулу → отрази в [[B2B_RULES]]
- Добавил поле в форму → отрази в [[CHECKOUT_FLOW]]
- Обновил структуру проекта → отрази в [[ARCHITECTURE]]

## 🚀 После завершения задачи

После внесения всех изменений в код и документацию:

1. **Выполнить `git add`** всех изменённых и созданных файлов
2. **Закоммитить изменения** с осмысленным сообщением
3. **Выполнить `git push`** на GitHub

> ⚠️ **Строгое правило:** ИИ-агенты обязаны использовать [[WikiLinks]] при редактировании docs/ и выполнять git push после завершения задач.
