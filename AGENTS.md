# 🤖 Инструкция для AI-агентов

> Последнее обновление: 29.07.2026

## ⚠️ ОБЯЗАТЕЛЬНОЕ ПРАВИЛО

**Любой AI-агент, работающий с проектом Lunchistan, ОБЯЗАН перед выполнением любой задачи прочитать файлы из папки `docs/`.**

## 📂 Файлы для чтения

| Файл                 | Описание                                  |
| -------------------- | ----------------------------------------- |
| `docs/ARCHITECTURE.md` | Полное описание архитектуры, стека, компонентов, типов и управления состоянием |
| `docs/B2B_RULES.md`  | Бизнес-логика B2B-подписки, ценообразование, правила формы заказа |

## 📋 Процедура

1. **Перед любыми изменениями кода** — прочитать оба документа из `docs/`
2. **После любых изменений кода** — обновить соответствующие файлы в `docs/`, чтобы Obsidian-хранилище содержало актуальный контекст проекта
3. **При добавлении новых компонентов/функций** — дополнить `docs/ARCHITECTURE.md` разделом о них
4. **При изменении бизнес-логики** — обновить `docs/B2B_RULES.md`

## 🔄 После выполнения задачи

Всегда синхронизируй документацию:

- Обновил состояние → отрази в ARCHITECTURE.md (раздел 5 «Управление состоянием»)
- Добавил новый экран/компонент → отрази в ARCHITECTURE.md (раздел 3 «Структура компонентов»)
- Изменил цены/формулу → отрази в B2B_RULES.md (раздел 3 «Ценообразование»)
- Добавил поле в форму → отрази в B2B_RULES.md (раздел 9 «Форма оформления заказа»)
